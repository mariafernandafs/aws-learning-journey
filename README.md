## 📖 Sobre o projeto

Este repositório reúne estudos, experimentos e materiais de referência sobre **Amazon Web Services (AWS)**, com foco na compreensão dos fundamentos de computação em nuvem, serviços, arquiteturas e boas práticas.

A proposta vai além de conhecer ferramentas: busca compreender **quais problemas cada serviço resolve, como funciona e em quais cenários sua utilização faz sentido**.

O conteúdo é construído de forma incremental, combinando fundamentos teóricos, experiências práticas e comparações entre provedores de nuvem.

Todo o material é compartilhado publicamente para apoiar o aprendizado contínuo e a troca de conhecimento com a comunidade.

## 🎯 Objetivos

- 📚 Consolidar fundamentos e conceitos de computação em nuvem.
- ☁️ Explorar serviços e soluções do ecossistema AWS.
- 🛠️ Documentar laboratórios, experimentos e implementações práticas.
- 🔄 Comparar abordagens e serviços entre AWS, Azure e Oracle Cloud.
- 🏗️ Desenvolver uma visão arquitetural, considerando boas práticas e *trade-offs*.
- 🤝 Compartilhar conhecimento e incentivar a colaboração técnica.

## 🧪 Hands-on Labs

Os laboratórios buscam conectar conceitos à prática, documentando, sempre que aplicável:

- **🎯 Objetivo:** problema ou cenário explorado.
- **🏗️ Arquitetura:** componentes e serviços utilizados.
- **⚙️ Implementação:** etapas e configurações necessárias.
- **📊 Evidências:** resultados, testes e observações.
- **🔐 Custos e segurança:** cuidados durante o provisionamento.
- **🧹 Cleanup:** remoção dos recursos para evitar cobranças desnecessárias.
- **💡 Lessons Learned:** dificuldades, descobertas e possíveis melhorias.

## 🌎 Multicloud Perspective

Compreender diferentes provedores de nuvem contribui para uma visão tecnológica mais ampla e para decisões arquiteturais fundamentadas.

Este projeto também explora relações entre os ecossistemas:

- **AWS** — Amazon Web Services
- **Azure** — Microsoft Azure
- **OCI** — Oracle Cloud Infrastructure

O objetivo não é apenas identificar serviços equivalentes, mas compreender suas **características, limitações, diferenças e aplicações**.

## 🌱 Learning in Public

O aprendizado é um processo contínuo, construído por meio de estudo, experimentação, questionamentos e revisão de conceitos.
